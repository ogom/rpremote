# 構造物

[English](structure.md)

> **大仙古墳**（大山古墳／大仙陵古墳／仁徳天皇陵古墳）｜大阪府堺市堺区大仙町

## 1. 概要

大仙古墳は、大阪府堺市堺区大仙町に所在する日本最大の前方後円墳である。5世紀中頃（古墳時代中期中葉）に築造されたと考えられており、宮内庁により仁徳天皇の陵墓「百舌鳥耳原中陵（もずのみみはらのなかのみささぎ）」として治定されている。

2019年には、「百舌鳥・古市古墳群―古代日本の墳墓群」の構成資産としてユネスコ世界文化遺産に登録された。

| 項目         | 内容                                  |
| ------------ | ------------------------------------- |
| 墳形         | 前方後円墳                            |
| 築造時期     | 5世紀中頃                             |
| 墳丘長       | 約486 m                               |
| 墳丘の向き   | 後円部が北側、前方部が南側            |
| 墳丘の構造   | 3段築成                               |
| 周囲の構造   | 三重の濠と、その間に設けられた2つの堤 |
| 濠を含む全長 | 約840 m                               |

本資料では、次の構造要素を中心に整理する。

- 3段築成の墳丘
- 三重の濠
- 濠の間に設けられた2つの堤
- 中堤上に築造された2基の円墳（付属墳）

## 2. 墳丘の構造

墳丘は前方後円形で、**後円部を北側、前方部を南側**に向けて築かれている。くびれ部の左右には、**造出し（つくりだし）**と呼ばれる方形の張り出しが設けられている。

墳丘には葺石（ふきいし）が施され、円筒埴輪や形象埴輪が配置されていたことが確認されている。

### 規模

| 部位       |     規模 |
| ---------- | -------: |
| 墳丘長     |  約486 m |
| 後円部直径 |  約249 m |
| 後円部高さ | 約35.8 m |
| 前方部幅   |  約307 m |
| 前方部高さ | 約33.9 m |

### 3段築成

墳丘は、下から順に次の3段で構成される。

1. **1段目（最下段）**：墳丘の基底部を構成する、最も広い段
2. **2段目（中段）**：1段目の上に築かれた中間の段
3. **3段目（上段）**：墳頂部を形成する最上段

## 3. 濠と堤の構成

大仙古墳の墳丘は、**三重の濠**に囲まれている。

> 三重になっているのは**濠**である。3本の濠の間に、2つの堤が設けられている。

中心から外側へ向かう構造は、次のとおりである。

```text
墳丘
  ↓
内濠
  ↓
内側の堤
  ↓
第2の濠
  ↓
中堤
  ↓
外濠
  ↓
外周部
```

| 順序 | 構造     | 種別       | 概要                                       |
| ---: | -------- | ---------- | ------------------------------------------ |
|    1 | 墳丘     | 前方後円墳 | 墳丘長約486 m、3段築成                     |
|    2 | 内濠     | 濠         | 墳丘を直接取り囲む、最も内側の濠           |
|    3 | 内側の堤 | 堤         | 内濠と第2の濠の間に位置する                |
|    4 | 第2の濠  | 濠         | 内側の堤と中堤の間に位置する               |
|    5 | 中堤     | 堤         | 後円部側に茶山古墳と大安寺山古墳が所在する |
|    6 | 外濠     | 濠         | 三重濠の最外周に位置する                   |
|    7 | 外周部   | 墓域       | 大仙古墳と関係する複数の古墳が分布する     |

### 外濠

現在の外濠は、**明治時代に掘り直されたもの**である。大仙古墳は三重の濠によって巨大な墓域を形成しており、濠を含む全長は約840 mに達する。

## 4. 中堤上の円墳（付属墳）

後円部側の中堤には、次の2基の円墳が築造されている。

- 茶山古墳
- 大安寺山古墳

これらは、単に「円墳が外濠へ張り出している」構造ではない。**中堤自体が外濠側へステージ状に広がり、その部分に円墳が築造されている**。

| 名称         | 墳形 | 墳丘径 |    高さ | 築成              | 中堤との関係                     |
| ------------ | ---- | -----: | ------: | ----------------- | -------------------------------- |
| 茶山古墳     | 円墳 | 約56 m | 約9.3 m | 2段築成とみられる | 中堤が外濠側へ広がった部分に築造 |
| 大安寺山古墳 | 円墳 | 約62 m | 約9.7 m | 2段築成とみられる | 中堤が外濠側へ広がった部分に築造 |

いずれも大仙古墳の中堤と一体化した構造を持つ。

## 5. 周辺の古墳

大仙古墳の周辺には、中堤上の茶山古墳・大安寺山古墳のほかにも複数の古墳が分布している。

代表例は次のとおりである。

- 源右衛門山古墳
- 竜佐山古墳
- 狐山古墳
- 銅亀山古墳
- 孫太夫山古墳

これらは大仙古墳と密接な関係を持ち、大仙古墳を中心とする墓域を構成していると考えられる。ただし、大仙古墳との具体的な関係や「陪塚」としての位置づけには考古学的な検討が必要であり、すべてを一律に陪塚と断定することは避ける。

## 6. 構造上の要点

1. 墳丘は、後円部を北、前方部を南に向けた**3段築成の前方後円墳**である。
2. 墳丘の周囲には**三重の濠**があり、その間に**2つの堤**が設けられている。
3. 後円部側の中堤には、**茶山古墳**と**大安寺山古墳**が所在する。
4. 2基の円墳は、**中堤が外濠側へステージ状に広がった部分**に築造されている。
5. 現在の外濠は、**明治時代に掘り直されたもの**である。
6. 外周には複数の古墳が分布し、大仙古墳を中心とする大規模な墓域を形成している。
