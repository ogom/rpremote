# LED配置

[English](led_layout.md)

この資料は、[構造確認資料](structure.ja.md)で説明する大仙古墳の構造を、模型の572個のWS2812B LEDへどのように対応付けているかを示します。物理アドレスの唯一の定義は[`led_layout.rb`](../mrbgems/daisenkofun-illuminations/mrblib/daisenkofun/led_layout.rb)です。LEDの追加、配線順の変更、区間の調整はRubyファイルだけを変更し、この資料には対応関係を記載します。

## 構造資料とLED輪郭の対応

[構造確認資料の「3段築成」](structure.ja.md#3段築成)に対応して、墳丘を上段、中段、最下段の3輪郭で表現します。その外側には、[三重の濠と2つの堤](structure.ja.md#3-濠と堤の構成)のうち、LEDを設置する内側の堤と中堤を加えます。この5輪郭が`SEGMENT_RANGES`の行と同じ順序です。

| 構造上の位置 | 構造資料上の要素    | `LedLayout`の定数 | LEDアドレス | LED数 | 模型での表現                                  |
| -------------: | ------------------- | ----------------- | ----------: | ----: | --------------------------------------------- |
|              1 | 墳丘3段目（上段）   | `MOUND_TOP`       |     `0..51` |    52 | 墳頂部の前方後円形輪郭                        |
|              2 | 墳丘2段目（中段）   | `MOUND_MIDDLE`    |   `52..131` |    80 | 墳丘中段の前方後円形輪郭                      |
|              3 | 墳丘1段目（最下段） | `MOUND_BASE`      |  `132..229` |    98 | 墳丘基底部の前方後円形輪郭                    |
|              4 | 内濠                | 定数なし          |        なし |     0 | `MOUND_BASE`と`INNER_BANK`の発光で両岸を表現  |
|              5 | 内側の堤            | `INNER_BANK`      |  `230..385` |   156 | 内濠と第2の濠の間にある堤の輪郭               |
|              6 | 第2の濠             | 定数なし          |        なし |     0 | `INNER_BANK`と`MIDDLE_BANK`の発光で両岸を表現 |
|              7 | 中堤                | `MIDDLE_BANK`     |  `386..569` |   184 | 第2の濠と外濠の間にある堤の輪郭               |
|             7a | 茶山古墳            | `CHAYAMA`         |       `570` |     1 | 後円部側の中堤上にある付属墳                  |
|             7b | 大安寺山古墳        | `DAIANJIYAMA`     |       `571` |     1 | 後円部側の中堤上にある付属墳                  |
|              8 | 外濠                | 定数なし          |        なし |     0 | `MIDDLE_BANK`の発光で内岸を表現               |

`LED_COUNT`は、5輪郭の570個と付属墳2個を合わせた572です。構造資料にある濠そのものと外周部にはLEDを割り当てていません。水面の演出では、`MOAT_BOUNDARIES`に定義した隣接輪郭を岸として光らせます。

```text
中心
  墳丘3段目  MOUND_TOP       0..51
  墳丘2段目  MOUND_MIDDLE   52..131
  墳丘1段目  MOUND_BASE    132..229
  内濠        LEDなし        境界 [MOUND_BASE, INNER_BANK]
  内側の堤    INNER_BANK    230..385
  第2の濠     LEDなし        境界 [INNER_BANK, MIDDLE_BANK]
  中堤        MIDDLE_BANK   386..569
  外濠        LEDなし        境界 [MIDDLE_BANK]
外側
```

茶山古墳と大安寺山古墳は、[構造確認資料の説明](structure.ja.md#4-中堤上の円墳付属墳)どおり中堤上の円墳として扱います。主輪郭の`MIDDLE_BANK`には含めず、後円部側に置く独立したアクセントLEDとして定義しています。

## 方位と配線順

大仙古墳の後円部を北、前方部を南として模型を見ます。

```text
     北北西（茶山古墳）  北北東（大安寺山古墳）
             北（後円部）
                  ↑
       左辺（西）     右辺（東）
                  ↓
             南（前方部）
```

各主輪郭の配線順は、前方部先端から左辺を通って後円部へ進み、右辺を通って前方部先端へ戻ります。

```text
左辺下部 -> 左辺上部 -> 円部（後円部） -> 右辺上部 -> 右辺下部
```

`SEGMENT_RANGES`では、すべての輪郭をこの5区間で定義します。各行の位置は`MOUND_TOP`から`MIDDLE_BANK`までの定数値`0..4`に対応します。

| 輪郭           |   左辺下部 |   左辺上部 | 円部（後円部） |   右辺上部 |   右辺下部 |
| -------------- | ---------: | ---------: | -------------: | ---------: | ---------: |
| `MOUND_TOP`    |     `0..1` |    `2..17` |       `18..33` |   `34..49` |   `50..51` |
| `MOUND_MIDDLE` |   `52..57` |   `58..74` |      `75..108` | `109..125` | `126..131` |
| `MOUND_BASE`   | `132..140` | `141..159` |     `160..201` | `202..220` | `221..229` |
| `INNER_BANK`   | `230..248` | `249..282` |     `283..333` | `334..367` | `368..385` |
| `MIDDLE_BANK`  | `386..407` | `408..446` |     `447..509` | `510..547` | `548..569` |

輪郭全体の区間、左右の走査順、後円部の並び、南北方向の行は、`SEGMENT_RANGES`から起動時に生成されます。したがって、演出コードは個別のLED番号ではなく、構造を表す定数やAPIを使用できます。

## 演出用API

| API                                       | 用途                                                         |
| ----------------------------------------- | ------------------------------------------------------------ |
| `outline_range(outline)`                  | 指定した輪郭全体のLED区間を返します。                        |
| `outline_order(outline)`                  | 指定した輪郭を配線順にたどる配列を返します。                 |
| `inside_to_outside_order`                 | 構造資料の中心から外側へ、墳丘上段から中堤まで進む順序です。 |
| `outside_to_inside_order`                 | 構造資料の外側から中心へ、中堤から墳丘上段まで進む順序です。 |
| `forepart_to_circle_order(outline, side)` | 指定した左右の前方部から後円部へ進む順序です。               |
| `circle_to_forepart_order(outline, side)` | 指定した左右の後円部から前方部へ進む順序です。               |
| `scene_rows`                              | 北から南までを21行に対応付けた配列です。                     |
| `north_to_south_order`                    | `scene_rows`を北から南へたどる順序です。                     |
| `attached_scene_position(index)`          | 茶山古墳または大安寺山古墳の演出位置を返します。             |

この対応により、構造ガイドや水面の演出は、構造確認資料にある「3段築成」「三重の濠」「2つの堤」「中堤上の2基の円墳」を、模型上のLED輪郭へ一貫して置き換えられます。
