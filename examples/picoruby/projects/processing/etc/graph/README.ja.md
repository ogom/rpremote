# IMU姿勢グラフ

[English](README.md)

[`graph.pde`](graph.pde)は、Pico 2から受信した加速度、角速度、推定姿勢を時系列で表示します。現在値は画面上部、履歴は3つのグラフに表示します。

## 表示する値

| 表示 | 値 | 単位 | 意味 |
| --- | --- | --- | --- |
| Acceleration | `ax`、`ay`、`az` | g | センサー座標の各軸に加わる加速度です。静止時には重力により3軸の合成値が約1 gになります。 |
| Gyroscope | `gx`、`gy`、`gz` | degree/s | センサー座標の各軸まわりの角速度です。正方向は各軸に対する右手系に従います。 |
| Orientation | `roll`、`pitch`、`yaw` | degree | Pico 2側で加速度と角速度から推定した姿勢です。 |
| Temperature | `temp` | °C | IMU内部の温度です。周囲温度と完全には一致しません。 |

各グラフでは、X軸またはrollを赤、Y軸またはpitchを緑、Z軸またはyawを青で表示します。横軸は受信順で、右側ほど新しい値です。現在の送信周期は20 Hz、履歴は300点なので、画面全体は約15秒を表します。

表示範囲は、加速度が-2〜+2 g、角速度が-250〜+250 degree/s、姿勢が-180〜+180 degreeです。範囲を超えた値はグラフ上端または下端に固定して描画しますが、上部の現在値には実際の数値を表示します。

## センサーの軸と設置方向

グラフはBMI270またはMPU6050のセンサー座標をそのまま表示し、設置方向を自動判定したり軸を入れ替えたりしません。

- +Zを上にして静止させると、通常は`ax ≈ 0`、`ay ≈ 0`、`az ≈ +1`になります。
- +Yを上にして静止させると、通常は`ax ≈ 0`、`ay ≈ +1`、`az ≈ 0`になります。
- -Yを上にした場合は`ay ≈ -1`になります。

現在の姿勢推定はZ-upを水平姿勢として扱います。そのためY-upで設置すると、センサーの読み取りが正常でもrollまたはpitchは約90 degreeを示します。Y-upを水平として扱うには、PicoRuby側で軸変換を追加する必要があります。

## roll、pitch、yaw

- `roll`はX軸まわりの回転です。
- `pitch`はY軸まわりの回転です。
- `yaw`はZ軸まわりの回転です。

航空機に例えると、次の動きです。

| 姿勢 | 航空機の回転軸 | 動き |
| --- | --- | --- |
| roll | 機首から尾翼へ通る前後軸 | 左右の翼を傾ける動きです。 |
| pitch | 左翼から右翼へ通る左右軸 | 機首を上げ下げする動きです。 |
| yaw | 機体を上下に通る垂直軸 | 機首を左右へ向ける動きです。 |

この対応は、センサーの+Xを機首方向、+Yを翼方向、+Zを機体上方向に取り付けた場合です。センサーの設置方向が異なると、表示されるroll、pitch、yawと実際の機体動作の対応も変わります。

rollとpitchは重力方向で補正されます。BMI270とMPU6050には磁気センサーがないため、yawは起動時を基準にした相対角度です。時間とともにドリフトし、方位磁針のような絶対方位にはなりません。

## 受信データとの対応

現在のストリームは次のCSVを20 Hzで送信します。

```text
IMU_DATA,sensor,timestamp_ms,temperature_c,ax_g,ay_g,az_g,gx_dps,gy_dps,gz_dps,q0,q1,q2,q3,roll_deg,pitch_deg,yaw_relative_deg,posture,gesture
```

`graph.pde`はセンサー名、時刻、温度、加速度、角速度、roll、pitch、yawを使用します。`q0`〜`q3`、`posture`、`gesture`は受信しますが、このグラフには描画しません。

PicoRuby側が姿勢列を含まない短い形式を送った場合に限り、Processing側の相補フィルターでroll、pitch、yawを推定し、最初の100サンプルでジャイロバイアスを求めます。現在のストリームは姿勢列を含むため、Pico 2側で推定した値を優先します。

## 操作と確認

Processing 4で[`graph.pde`](graph.pde)を開いて実行します。既定では`/dev/cu.usbmodem101`を優先し、見つからない場合は最初の`/dev/cu.usbmodem*`を選びます。

Processing Consoleには、受信したセンサー名、時刻、加速度、角速度、姿勢を1秒ごとに表示します。画面に値が出ない場合は、Consoleで選択されたポートと`IMU received`の表示を確認してください。Processingがポートを使用している間は、同じポートで`rpremote monitor`を実行できません。

`R`キーはProcessing側の履歴と、短い入力形式で使用する相補フィルターをリセットします。現在のPicoRubyストリームが行う2秒間のジャイロキャリブレーションは再実行しません。Pico側のキャリブレーションをやり直す場合はストリームを再起動し、センサーを2秒間静止させます。
