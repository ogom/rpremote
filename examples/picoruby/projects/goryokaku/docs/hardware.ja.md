# ハードウェアと安全上の注意

[English](hardware.md)

## 配線

| 部品              | 信号 | Raspberry Pi Pico 2               |
| ----------------- | ---- | --------------------------------- |
| WS2812B           | DIN  | GP14                              |
| タッチスイッチ    | 出力 | GP21（内部プルアップ、押下時GND） |
| PWMブザー／アンプ | 信号 | GP18                              |
| MPU6050           | SDA  | GP16                              |
| MPU6050           | SCL  | GP17                              |
| MPU6050           | VCC  | 3V3(OUT)                          |
| すべての部品      | GND  | 共通GND                           |

`main.rb`と`Goryokaku::Application::Config`の既定値はこの表のPIN割り当てに一致します。配線を変える場合は、Configへ渡す値を変更してください。

MPU6050は、展示時のZ-UPで模型面が水平になり、演奏時のY-UPで星形本体の組5が上部になる向きに固定します。演奏時はZ軸を振る奏法の往復方向と、叩く奏法の打撃方向として使用します。滑らかな往復と鋭いjerkによって2つの奏法を区別します。

## LED電源

380個のWS2812BをPico 2のGPIOや3V3(OUT)から給電しないでください。LED仕様と同時点灯条件に合う外部5 V電源を用意し、Pico 2とGNDを共通化してください。電源の定格だけでなく、配線の電流容量、電圧降下、給電点、コネクター、ヒューズ、温度も確認してください。

全LEDが最大白色で1個あたり60 mAを消費する条件を設計上限とすると、380個では22.8 Aです。実際の値は使用するLEDと演出の輝度で変わるため、LEDのデータシートと実測値を優先してください。

5 V駆動のLEDには、3.3 Vから5 Vへのロジックレベル変換を推奨します。データ線の直列抵抗と電源端のバルクコンデンサーは、使用するLED製品の推奨回路に従ってください。

## 操作時の注意

- USBやLED電源を切ってから配線を変更してください。
- MPU6050のI2C信号へ5 Vを加えないでください。
- ブザーやスピーカーをGPIOから直接大電流で駆動しないでください。必要に応じてアンプまたはドライバーを使用してください。
- 初回はLED電流を測定できる状態で短い演出を確認してください。
