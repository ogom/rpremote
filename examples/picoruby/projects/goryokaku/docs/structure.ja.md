# 構造物

[English](structure.md)

> **五稜郭**｜北海道函館市五稜郭町

## 概要

五稜郭は、江戸幕府が箱館奉行所の防御を目的として築いた西洋式土塁です。蘭学者の武田斐三郎が設計し、安政4年（1857年）に着工、元治元年（1864年）に箱館奉行所が移転しました。

5つの稜堡が外側へ張り出し、星形の五角形を作ります。低く厚い土塁と石垣、その外側の水堀を組み合わせ、突出部から隣接する壁面を側面射撃できる構造です。南西側の正面には、入口を守る半月堡が1基あります。

| 項目 | 内容 |
| ---- | ---- |
| 形式 | 西洋式土塁（稜堡式城郭） |
| 主な構造 | 5つの稜堡、本塁、低塁、石垣、水堀 |
| 正面 | 南西側 |
| 正面の出塁 | 半月堡（馬出塁）1基 |
| 堀内側の面積 | 約125,500 m² |
| 水堀の面積 | 約56,400 m² |
| 水堀の幅・深さ | 最大約30 m・約4〜5 m |
| 堀の外周 | 約1.8 km |
| 文化財指定 | 国指定特別史跡「五稜郭跡」 |

## 星形土塁

稜堡は城壁から外側へ突き出した防御施設です。五稜郭では5つの稜堡を直線状の土塁で結び、星形の輪郭を形成しています。高い石壁ではなく土塁を主体とすることで、砲撃を受ける面積と石材の飛散を抑えています。

主要な土塁である本塁は幅約27〜30 m、高さ約5〜7 mです。堀を掘った土を層状に突き固める版築で造られました。3か所の出入口では一部が石垣造りで、南西正面には石を張り出す「刎ね出し」があります。

本塁と水堀の間には幅約10 m、高さ約2 mの低塁があります。模型では、5方向をそれぞれ2辺に分けた合計10セグメントで星形本体を表します。

## 水堀、半月堡、郭内

水堀は星形の本塁に沿って巡り、その外周は約1.8 kmです。中心から外側への関係は次のとおりです。

```text
郭内（箱館奉行所）→ 本塁・石垣 → 低塁 → 水堀 → 堀外周
```

半月堡は南西正面の入口を守る三角形状の出塁で、「馬出塁」とも呼ばれます。当初は5か所に置く計画でしたが、実際に造られたのは1か所です。星形本体とは別の防御施設なので、模型でも独立したLEDゾーンにしています。

現在の出入口は南西、東、北の3か所です。各入口の内側には、郭内を直接見通せないようにする見隠塁があります。郭内中央の箱館奉行所は明治4年（1871年）に大半が解体されましたが、調査に基づいて庁舎の一部が復元され、2010年に公開されました。

## 模型への置き換え

本プロジェクトでは、代表長さ約535 mを模型上の276 mmとして扱います。

```text
535,000 mm ÷ 276 mm ≒ 1,938
```

縮尺は概ね1/1,938です。これは起伏や構造の相対関係を検討するための目安で、史跡の細部を厳密に復元する施工寸法ではありません。代表長さ535 mと堀外周約1.8 kmは測定対象が異なります。

| 実物の構造 | 実物寸法 | 模型換算の目安 |
| ---------- | -------: | --------------: |
| 本塁の高さ | 約5〜7 m | 約2.6〜3.6 mm |
| 本塁の幅 | 約27〜30 m | 約13.9〜15.5 mm |
| 低塁の高さ・幅 | 約2 m・約10 m | 約1.0 mm・約5.2 mm |
| 水堀の最大幅・深さ | 約30 m・約4〜5 m | 約15.5 mm・約2.1〜2.6 mm |

380個のLEDは、構造を識別して演出するため次の3ゾーンに分けます。

| ゾーン | LED番号 | 個数 | 模型上の対象 |
| ------ | -------: | ---: | ------------ |
| `STAR` | `0..169` | 170 | 5つの稜堡を含む星形本体 |
| `RAVELIN` | `170..189` | 20 | 南西正面の半月堡 |
| `OUTER` | `190..379` | 190 | 水堀外側の輪郭 |

実際の冬季イベント「五稜星の夢」を着想源としていますが、実物の電球配置をそのまま縮小したものではありません。半月堡や外周を独立して制御できるよう、史跡の特徴を演出用に抽象化しています。正確な配線範囲は[LED配置](led_layout.ja.md)を参照してください。

## 姿勢

展示と構造図では模型面を水平にするZ-UPを基準にします。タンバリン演奏では模型面を起こし、組5が上部になるY-UPで保持します。このときZ軸は模型面に垂直な振りと打撃の方向です。

姿勢が変わってもLEDアドレスや構造ゾーンは変わりません。Y-UPは演奏動作と光の進行方向を解釈するための基準です。
