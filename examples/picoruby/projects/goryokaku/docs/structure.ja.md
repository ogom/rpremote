# 構造物

> **五稜郭**｜北海道函館市五稜郭町

## 1. 概要

五稜郭は、江戸幕府が箱館奉行所の防御を目的として築いた西洋式土塁である。設計は蘭学者の武田斐三郎が担当し、安政4年（1857年）に着工、元治元年（1864年）に箱館奉行所が移転した。

平面は、5つの稜堡（りょうほ）が外側へ張り出す星形の五角形である。土塁と石垣、その外側の水堀を組み合わせ、突出部から隣接する壁面を側面射撃できる構造になっている。南西側の正面には、入口を守る半月堡（はんげつほ）が1基設けられている。

| 項目 | 内容 |
| ---- | ---- |
| 形式 | 西洋式土塁（稜堡式城郭） |
| 主な構造 | 5つの稜堡、本塁、低塁、石垣、水堀 |
| 正面 | 南西側 |
| 正面の出塁 | 半月堡（馬出塁）1基 |
| 堀内側の面積 | 約125,500 m² |
| 水堀の面積 | 約56,400 m² |
| 水堀の幅 | 最大約30 m |
| 水堀の深さ | 約4〜5 m |
| 堀の外周 | 約1.8 km |
| 文化財指定 | 国指定特別史跡「五稜郭跡」 |

本資料では、次の構造要素とイルミネーション模型上の対応を整理する。

- 五角形を形成する5つの稜堡
- 本塁、低塁、石垣
- 本塁を囲む水堀
- 南西正面の半月堡
- 郭内の箱館奉行所と出入口
- 縮尺模型の寸法とLED配置

## 2. 星形土塁の構造

### 稜堡

稜堡は、城壁から外側へ突き出した防御施設である。五稜郭には5つの稜堡があり、それらを直線状の土塁で結ぶことで星形の輪郭を形成している。

突出した稜堡から隣の壁面方向を見通せるため、正面と側面から交差して防御できる。砲撃を受ける面積と石材の飛散を抑えるため、高い石壁を主体とせず、低く厚い土塁を主体としていることも特徴である。

模型の星形部分では、5方向をそれぞれ左右2辺に分け、合計10セグメントとして扱う。

```text
5方向 × 左右2辺 = 10セグメント
```

### 本塁

星形の主要な土塁を本塁（ほんるい）という。函館市の資料では、本塁は**幅約27〜30 m、高さ約5〜7 m**とされる。堀を掘った際の土を層状に突き固める版築（はんちく）工法で築かれている。

郭内への出入口となる3か所では、本塁の一部が石垣造りになっている。特に南西側正面の石垣上部には、石を張り出して侵入しにくくする「刎ね出し」が設けられている。「武者返し」または「忍び返し」とも呼ばれる。

### 低塁

本塁と水堀の間には、**幅約10 m、高さ約2 m**の低塁（ているい）が設けられている。本塁より低い位置で、その外周を補助する土塁である。

## 3. 水堀と外周

本塁の外側には、星形の輪郭に沿って水堀が巡る。水堀は最大幅約30 m、深さ約4〜5 mで、堀の外周は約1.8 kmである。

中心から外側へ向かう基本構成は、次のとおりである。

```text
郭内（箱館奉行所）
  ↓
本塁・石垣
  ↓
低塁
  ↓
水堀
  ↓
堀外周・長斜坂
```

| 順序 | 構造 | 概要 |
| ---: | ---- | ---- |
| 1 | 郭内 | 箱館奉行所と付属施設が置かれた内側の区域 |
| 2 | 本塁 | 5つの稜堡を形成する主要な土塁 |
| 3 | 石垣 | 主に出入口部分を補強し、正面には刎ね出しがある |
| 4 | 低塁 | 本塁と水堀の間に設けられた低い土塁 |
| 5 | 水堀 | 星形の本塁と半月堡を囲む堀 |
| 6 | 堀外周 | 現在は外周約1.8 kmの園路が巡る |

正面側の堀外には、堀から上げた土を盛った低い土手「長斜坂（ちょうしゃはん）」が残る。

## 4. 半月堡

半月堡は、南西側の正面入口を防御する三角形状の出塁で、「馬出塁」とも呼ばれる。水堀の内側にあり、本塁正面との間を二の橋が結ぶ。

当初の設計では5か所に配置する計画だったが、工事規模の縮小などにより、実際に築かれたのは正面の1か所だけである。北側中央部に土坂の開口部があり、そのほかの部分は刎ね出しを備えた石垣で囲まれている。

半月堡は五稜郭の星形本体とは別の防御要素であるため、本模型でも独立したLEDゾーンとして扱う。

## 5. 出入口と郭内

現在の出入口は、南西正面の一の橋・二の橋側、東側、北側の裏門橋側の3か所である。築造当時の絵図には橋が5か所描かれているが、2か所は明治2年（1869年）の箱館戦争時に撤去されたと考えられている。

各出入口の内側には、外部から郭内を直接見通せないようにする見隠塁（みかくしるい）がある。規模はそれぞれ、長さ約44 m、幅約14 m、高さ約4 mである。

郭内中央には箱館奉行所が置かれていた。明治4年（1871年）に庁舎と付属建物の大半が解体されたが、発掘調査や文献調査をもとに庁舎の一部が復元され、2010年に公開された。

## 6. イルミネーション模型の縮尺

本プロジェクトでは、五稜郭の代表長さを**約535 m**、模型上の対応寸法を**276 mm**として扱う。

```text
535,000 mm ÷ 276 mm ≒ 1,938
```

したがって、模型の縮尺は概ね**1/1,938**となる。ただし、535 mは本模型の設計基準として採用した代表寸法であり、堀外周約1.8 kmとは測定対象が異なる。

この縮尺で主要な高さを換算すると、次のようになる。

| 実物の構造 | 実物寸法 | 1/1,938換算 |
| ---------- | -------: | ----------: |
| 本塁の高さ | 約5〜7 m | 約2.6〜3.6 mm |
| 本塁の幅 | 約27〜30 m | 約13.9〜15.5 mm |
| 低塁の高さ | 約2 m | 約1.0 mm |
| 低塁の幅 | 約10 m | 約5.2 mm |
| 水堀の最大幅 | 約30 m | 約15.5 mm |
| 水堀の深さ | 約4〜5 m | 約2.1〜2.6 mm |
| 見隠塁の高さ | 約4 m | 約2.1 mm |

縮尺換算値は、史跡の細部を厳密に復元するための施工寸法ではなく、模型の起伏や各構造の相対関係を検討するための目安とする。

## 7. LEDゾーンとの対応

### 模型の姿勢

構造とイルミネーションの配置図は、模型面を水平に置くZ-UPを基準とする。タンバリン演奏時は模型面を起こしてY-UPとし、星形本体の組5（`line5_a`、`line5_b`）が上部に来る向きで保持する。

```text
Z-UP（展示）                 Y-UP（演奏）
Z軸が上                     Y軸・組5が上
模型面: X-Y                 模型面: X-Y
                             打撃方向: Z
```

Y-UPではZ軸を模型面に垂直な振りの往復方向と打撃方向として検出する。滑らかな反転を振る奏法、鋭いjerkを叩く奏法として区別する。姿勢を変えてもLEDアドレスと構造ゾーンの定義は変えず、組5を演奏用走査の開始位置として扱う。

イルミネーション実装では、380個のLEDを3つのゾーンに分けている。

| ゾーン | LED番号 | 個数 | 模型上の対象 |
| ------ | ------- | ---: | ------------ |
| `STAR` | 0〜169 | 170 | 5つの稜堡を含む星形本体 |
| `RAVELIN` | 170〜189 | 20 | 南西正面の半月堡 |
| `OUTER` | 190〜379 | 190 | 水堀外側の外周線 |

星形本体の170個は、5方向を左右2辺ずつに分けた10セグメントへ割り当てる。8セグメントは各17個で、残る2セグメントはそれぞれ16個、18個となる。

```text
STAR      0 ─────────────── 169
RAVELIN                         170 ─ 189
OUTER                                      190 ─────────────── 379
```

この区分により、史跡の構造に対応した次の演出が可能になる。

- 星形本体の辺ごとの走査、左右対称点灯、虹色表示
- 半月堡のみの点灯、呼吸明滅、パルス表示
- 外周のみを周回するチェイス、コメット、波形表示
- 外周、半月堡、星形本体の順次点灯・消灯

実際の冬季イベント「五稜星の夢」では、堀の周囲を電球で星形に彩る。本模型はその景観を着想源としつつ、半月堡と外周を独立制御できるよう、実物の電球配置をそのまま縮小するのではなく演出用に再構成している。

## 8. 構造上の要点

1. 五稜郭は、5つの稜堡を持つ星形の西洋式土塁である。
2. 防御の主体は、幅約27〜30 m、高さ約5〜7 mの低く厚い本塁である。
3. 本塁と水堀の間には、幅約10 m、高さ約2 mの低塁がある。
4. 水堀は最大幅約30 m、深さ約4〜5 mで、外周は約1.8 kmである。
5. 半月堡は南西正面に1基だけ築かれ、正面入口を防御する。
6. 模型は約1/1,938を設計上の目安とし、380個のLEDを星形、半月堡、外周の3ゾーンに分ける。
7. LED配置は構造物の識別と演出制御を目的とした抽象化であり、史跡の電球数や配置を忠実に縮小したものではない。
8. タンバリン演奏はY-UPかつ組5が上の姿勢を基準とし、Z軸を振りと打撃の方向として扱う。
