# LED配置

[English](led_layout.md)

この資料は、[構造確認資料](structure.ja.md)で説明する五稜郭の構造を、模型の380個のWS2812 LEDへどのように対応付けているかを示します。物理アドレスの唯一の定義は[`led_layout.rb`](../mrbgems/goryokaku-illumination/mrblib/goryokaku-illumination/led_layout.rb)です。LEDの追加、配線順の変更、区間の調整を行う場合は、このRubyファイルと資料を同時に更新します。

## 構造資料とLEDゾーンの対応

[構造確認資料の「LEDゾーンとの対応」](structure.ja.md#7-ledゾーンとの対応)に基づき、380個のLEDを星形本体、半月堡、外周の3ゾーンへ分けます。

| 構造上の位置 | 構造資料上の要素 | `LedLayout`の定数 | LEDアドレス | LED数 | 模型での表現 |
| ------------: | ---------------- | ---------------- | -----------: | ----: | ------------ |
| 1 | 郭内 | 定数なし | なし | 0 | 内部はLED輪郭の内側として表現 |
| 2 | 本塁・5つの稜堡 | `ZONE_RANGES[STAR]` | `0..169` | 170 | 星形本体を10辺で表現 |
| 3 | 低塁・水堀 | 定数なし | なし | 0 | 星形と外周の間の空間として表現 |
| 4 | 南西正面の半月堡 | `ZONE_RANGES[RAVELIN]` | `170..189` | 20 | 星形本体とは独立した出塁 |
| 5 | 堀外周 | `ZONE_RANGES[OUTER]` | `190..379` | 190 | 水堀の外側を巡る連続した輪郭 |

`LED_COUNT`と`NUM_LEDS_ALL`はいずれも380です。水堀そのものや郭内にはLEDを割り当てず、発光する輪郭間の空間として扱います。

```text
中心
  郭内                 LEDなし
  星形本体 STAR          0..169    170個
  低塁・水堀            LEDなし
  半月堡 RAVELIN       170..189     20個
  堀外周 OUTER         190..379    190個
外側
```

3ゾーンはアドレス上では連続していますが、構造上は同心円状の単純な3層ではありません。半月堡は南西正面にだけある局所的な出塁で、外周は水堀の外側を一周する輪郭です。

## 星形本体のセグメント

星形本体は、5つの稜堡に対応する5組を、それぞれA辺とB辺に分けた10セグメントで構成します。配線順の10区間は`STAR_SEGMENT_RANGES`で定義します。

| 組 | セグメント | `STAR_SEGMENT_RANGES`位置 | LEDアドレス | LED数 | 通常の配列順 |
| --: | ---------- | -------------------: | -----------: | ----: | ------------ |
| 1 | `line1_a` | 0 | `0..16` | 17 | `0` → `16` |
| 1 | `line1_b` | 1 | `17..33` | 17 | `17` → `33` |
| 2 | `line2_a` | 2 | `34..50` | 17 | `34` → `50` |
| 2 | `line2_b` | 3 | `51..67` | 17 | `51` → `67` |
| 3 | `line3_a` | 4 | `68..84` | 17 | `68` → `84` |
| 3 | `line3_b` | 5 | `85..101` | 17 | `85` → `101` |
| 4 | `line4_a` | 6 | `102..118` | 17 | `102` → `118` |
| 4 | `line4_b` | 7 | `119..134` | 16 | `119` → `134` |
| 5 | `line5_a` | 8 | `135..151` | 17 | `135` → `151` |
| 5 | `line5_b` | 9 | `152..169` | 18 | `152` → `169` |

合計は次のとおりです。

```text
17 + 17 + 17 + 17 + 17 + 17 + 17 + 16 + 17 + 18 = 170
```

## 配線順と演出上の走査方向

物理アドレスは、星形本体、半月堡、外周の順に増加します。

```text
DATA IN
  │
  ├─ STAR      0 → 169
  ├─ RAVELIN 170 → 189
  └─ OUTER    190 → 379
```

星形の通常演出では、各セグメントを上表の配列順、つまり小さいアドレスから大きいアドレスへ走査します。`Patterns::Rainbow`と`Patterns::ParallelLeft`／`Patterns::ParallelRight`はこの順序を使用します。

花火演出の`star_rays`では、各組の2辺を同じ起点から外側へ伸びる光線として扱うため、A辺とB辺で走査方向が異なります。

| セグメント種別 | 花火の走査方向 | 例 |
| ---------------- | -------------- | -- |
| A辺 | 小 → 大 | `line1_a`: `0` → `16` |
| B辺 | 大 → 小 | `line1_b`: `33` → `17` |

```text
組1:  0 → 16       33 → 17
組2: 34 → 50       67 → 51
組3: 68 → 84      101 → 85
組4: 102 → 118    134 → 119
組5: 135 → 151    169 → 152
```

この反転は物理配線を逆にする指定ではなく、演出内で生成するLEDインデックス配列の順序です。

## 並列点灯グループ

星形の10辺は、5辺ずつの2グループに分けて並列走査できます。

| 実装 | セグメント位置 | 対象セグメント | セットリストのキー |
| ---- | ------------------- | -------------- | ------------------ |
| `Patterns::ParallelLeft` | `[4, 5, 6, 7, 8]` | `3-A`, `3-B`, `4-A`, `4-B`, `5-A` | `:parallel_left` |
| `Patterns::ParallelRight` | `[9, 0, 1, 2, 3]` | `5-B`, `1-A`, `1-B`, `2-A`, `2-B` | `:parallel_right` |

左右の見え方は模型を置く向きと観察方向に依存します。プログラムから選ぶ場合は、上表のセットリストキーと実際の対象セグメントを基準にします。

## タンバリン演奏時の組順

Y-UPで組5が上部に来る姿勢を演奏基準とします。`MUSICAL_GROUP_ORDER`は組5から右方向へ走査する順序を、0始まりの組インデックスで定義します。

```ruby
MUSICAL_GROUP_ORDER = [4, 0, 1, 2, 3] # 組5 → 組1 → 組2 → 組3 → 組4
```

Z軸の正方向への振りではこの順序、負方向への振りでは組5を起点に逆順で点灯します。振る奏法では現在の組を`FIREWORK`色で点灯し、直前の組を低輝度の残光として残します。半月堡と外周の点光も組の移動に合わせて色を変えます。

叩く奏法では、`fireworks`と同じ`star_rays`を使用し、星形中心から10セグメントの外側へ6フレームで多色の光を広げます。半月堡は白色と`FIREWORK`色を交互に点灯し、前半は外周の点光、後半は外周全体のフラッシュへ展開します。全体輝度は`Config::BRIGHTNESS`を上限とし、派手さを保ちながら瞬間電流を制限します。

## 半月堡ゾーン

半月堡は`170..189`の20個です。1本の連続区間として扱い、星形本体の10セグメントには含めません。

| 項目 | 内容 |
| ---- | ---- |
| 区間 | `ZONE_RANGES[RAVELIN] = [170, 189]` |
| LED数 | 20 |
| 既定色 | `RAVELIN_COLOR = [0, 200, 255]`（水色） |
| 主な走査 | `170` → `189` |

`Patterns::RavelinPulse`がこの区間だけを操作します。新しい半月堡演出も`Patterns::Base`を継承した個別クラスとして追加します。

## 外周ゾーン

外周は`190..379`の190個です。水堀外側を巡る閉じたリングとして扱います。

| 項目 | 内容 |
| ---- | ---- |
| 区間 | `ZONE_RANGES[OUTER] = [190, 379]` |
| LED数 | `OUTER_COUNT = 190` |
| 既定色 | `OUTER_COLOR = [255, 220, 50]`（ゴールド） |
| 通常の周回 | `190` → `379` → `190` |

`outer_ring(start_offset)`は、指定した起点からアドレスを増やし、終端を越えると`190`へ戻る配列を生成します。周回演出では、物理的な継ぎ目である`379`と`190`を隣接点として扱います。

`Patterns::OuterComet`などがこのリング構造を利用します。

## ゾーン別の演出クラス

| 対象 | API例 | 用途 |
| ---- | ----- | ---- |
| 全LED | `Patterns::WarmWhite`, `Patterns::FullZones` | 380個を操作 |
| 星形本体 | `Patterns::StarTwinkle`, `Patterns::SakuraBreathe` | `0..169`を操作 |
| 半月堡 | `Patterns::RavelinPulse` | `170..189`を操作 |
| 外周 | `Patterns::OuterComet` | `190..379`を操作 |
| 花火 | `Patterns::Fireworks` | 星形の10辺と外周リングを放射状に操作 |
| 対話演出 | `InteractivePlayer` | 姿勢表示、半月堡の選択色（赤／青）、確定時のセットリスト実行、タンバリン時の消灯を処理 |

全パターンとキーは[イルミネーション一覧](illuminations.ja.md)を参照してください。

## 配置変更時の確認事項

1. `ZONE_RANGES`の`0`から`379`までに欠番や重複がないこと。
2. 各ゾーンのLED数が、星形170個、半月堡20個、外周190個であること。
3. 星形10セグメントの合計が170個になること。
4. `main.rb`の`led_count`が380以上であること。
5. B辺を反転する花火の走査順が、模型上で中心から外側へ向くこと。
6. 外周の`379`と`190`が、模型上でもリングの継ぎ目として隣接すること。
7. 配線や向きを変更した場合は、並列点灯グループの左右表示も実機で確認すること。
8. Y-UPで組5が上部となり、Z軸の振り方向で`MUSICAL_GROUP_ORDER`の走査方向が反転すること。

この対応により、[構造確認資料](structure.ja.md)にある「5つの稜堡」「南西正面の半月堡」「水堀外周」を、独立したLEDゾーンと演出単位へ一貫して置き換えられます。
