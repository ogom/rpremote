# LED配置

[English](led_layout.md)

この資料は、五稜郭模型の構造と380個のWS2812 LEDの物理配置を対応付けます。アドレスの正本は
[`led_layout.rb`](../mrbgems/goryokaku-illumination/mrblib/goryokaku-illumination/led_layout.rb)です。

## ゾーン

| ゾーン | LEDアドレス | LED数 | 模型上の対象 |
| ------ | -----------: | ----: | ------------ |
| `STAR` | `0..169` | 170 | 5つの稜堡を含む星形本体 |
| `RAVELIN` | `170..189` | 20 | 南西正面の半月堡 |
| `OUTER` | `190..379` | 190 | 水堀外側の輪郭 |

```text
DATA IN → STAR 0..169 → RAVELIN 170..189 → OUTER 190..379
```

郭内と水堀そのものにはLEDを割り当てず、発光する輪郭の間の空間として表現します。半月堡は南西正面だけにある出塁であり、単純な同心円状の中間層ではありません。

## 星形本体

5つの稜堡をそれぞれA辺とB辺に分け、10セグメントとして配線します。

| 組 | A辺 | B辺 | LED数（A + B） |
| --: | ---: | ---: | ---------------: |
| 1 | `0..16` | `17..33` | 17 + 17 |
| 2 | `34..50` | `51..67` | 17 + 17 |
| 3 | `68..84` | `85..101` | 17 + 17 |
| 4 | `102..118` | `119..134` | 17 + 16 |
| 5 | `135..151` | `152..169` | 17 + 18 |

通常の演出では各区間を小さいアドレスから大きいアドレスへ走査します。`fireworks`の放射演出では、2辺を同じ起点から外側へ伸ばして見せるため、A辺を小→大、B辺を大→小の順に走査します。これは演出上の順序であり、物理配線を逆にする指定ではありません。

## タンバリン演奏時の向き

展示時は模型面を水平にするZ-UP、演奏時は組5が上部に来るY-UPを基準にします。正方向のZ軸の振りは組5→1→2→3→4、負方向の振りは組5→4→3→2→1の順に星形を移動します。

```text
正方向: 組5 → 組1 → 組2 → 組3 → 組4
負方向: 組5 → 組4 → 組3 → 組2 → 組1
```

振る奏法では移動方向に光の残像を作り、叩く奏法では`fireworks`と同じ中心から外側への放射を使います。姿勢を変えてもLEDアドレスとゾーンは変わりません。

## 半月堡と外周

半月堡は`170..189`の連続区間です。星形本体の10セグメントには含めず、選択状態や独立したパルスを表示します。

外周は`190..379`を閉じたリングとして扱います。周回演出では末端の`379`と先頭の`190`が模型上で隣接するため、配線時はこの継ぎ目を確認してください。

## 配置を変更するとき

配線順やLED数を変更したら、次を一緒に更新・確認します。

- `led_layout.rb`のゾーン、セグメント、走査順
- `main.rb`の`led_count`
- 花火が星形の中心から外側へ進むこと
- 外周の`379`と`190`が連続して見えること
- Y-UPで組5が上になり、Z軸の振り方向で走査が反転すること
- 本資料と[構造資料](structure.ja.md)

演出名と実行方法は[イルミネーション一覧](illuminations.ja.md)を参照してください。
