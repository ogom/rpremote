# LED配置

[English](led_layout.md)

この資料は、[構造確認資料](structure.ja.md)で説明する五稜郭の構造を、模型の380個のWS2812 LEDへどのように対応付けているかを示します。模型の組み立て、配線、演出の選択、点灯不良の確認に使用してください。物理アドレスの正本は[`led_layout.rb`](../mrbgems/goryokaku-illumination/mrblib/goryokaku-illumination/led_layout.rb)です。

## ゾーン

| ゾーン | LEDアドレス | LED数 | 模型上の対象 |
| ------ | -----------: | ----: | ------------ |
| `STAR` | `0..169` | 170 | 5つの稜堡を含む星形本体 |
| `RAVELIN` | `170..189` | 20 | 南西正面の半月堡 |
| `OUTER` | `190..379` | 190 | 水堀外側の輪郭 |

```text
中心
  郭内                  LEDなし
  星形本体 STAR           0..169   170個
  低塁・水堀             LEDなし
  半月堡 RAVELIN        170..189    20個（南西正面だけ）
  堀外周 OUTER          190..379   190個
外側
```

郭内と水堀そのものにはLEDを割り当てず、発光する輪郭の間の空間として表現します。半月堡は南西正面だけにある出塁であり、単純な同心円状の中間層ではありません。

物理配線は3ゾーンを次の順で1本につなぎます。

```text
DATA IN → STAR 0..169 → RAVELIN 170..189 → OUTER 190..379
```

## 星形本体

5つの稜堡をそれぞれA辺とB辺に分け、10セグメントとして配線します。通常の走査方向は、物理配線と同じ小さいアドレスから大きいアドレスです。

| 組 | 辺 | LEDアドレス | LED数 | 通常の走査方向 |
| --: | -- | -----------: | ----: | ---------------- |
| 1 | 1-A | `0..16` | 17 | `0` → `16` |
| 1 | 1-B | `17..33` | 17 | `17` → `33` |
| 2 | 2-A | `34..50` | 17 | `34` → `50` |
| 2 | 2-B | `51..67` | 17 | `51` → `67` |
| 3 | 3-A | `68..84` | 17 | `68` → `84` |
| 3 | 3-B | `85..101` | 17 | `85` → `101` |
| 4 | 4-A | `102..118` | 17 | `102` → `118` |
| 4 | 4-B | `119..134` | 16 | `119` → `134` |
| 5 | 5-A | `135..151` | 17 | `135` → `151` |
| 5 | 5-B | `152..169` | 18 | `152` → `169` |

10辺の合計は170個です。組4のB辺だけ16個、組5のB辺だけ18個で、それ以外は17個です。全辺が同じ個数ではないため、取り付け時に区間の境界を確認してください。

通常の演出では各区間を小さいアドレスから大きいアドレスへ走査します。`fireworks`の放射演出では、2辺を同じ起点から外側へ伸ばして見せるため、A辺を小→大、B辺を大→小の順に走査します。これは演出上の順序であり、物理配線を逆にする指定ではありません。

```text
組1:   0 → 16       33 → 17
組2:  34 → 50       67 → 51
組3:  68 → 84      101 → 85
組4: 102 → 118     134 → 119
組5: 135 → 151     169 → 152
```

## 左右の並列走査

`parallel_left`と`parallel_right`は、星形の10辺を5辺ずつに分けて同時に光を進めます。

| 演出キー | 対象となる辺 |
| -------- | ------------ |
| `parallel_left` | 3-A、3-B、4-A、4-B、5-A |
| `parallel_right` | 5-B、1-A、1-B、2-A、2-B |

左右は模型の置き方と観察方向によって見え方が変わります。配線確認では名称だけで判断せず、表の辺が点灯することを確認してください。

## タンバリン演奏時の向き

展示時は模型面を水平にするZ-UP、演奏時は組5が上部に来るY-UPを基準にします。正方向のZ軸の振りは組5→1→2→3→4、負方向の振りは組5→4→3→2→1の順に星形を移動します。

```text
正方向: 組5 → 組1 → 組2 → 組3 → 組4
負方向: 組5 → 組4 → 組3 → 組2 → 組1
```

振る奏法では、現在の組を明るくし、直前の組を低輝度で残して移動方向が分かる残像を作ります。半月堡と外周の点光も組の移動に合わせて色が変わります。

叩く奏法では、`fireworks`と同じ中心から外側への放射を使います。10辺へ多色の光が広がり、半月堡の点滅と外周の点光を経て、最後に外周全体が大きく発光します。姿勢を変えてもLEDアドレスとゾーンは変わりません。

## 半月堡

半月堡は`170..189`の連続区間です。星形本体の10セグメントには含めず、選択状態や独立したパルスを表示します。

| 確認項目 | 見え方 |
| -------- | ------ |
| `ravelin_pulse` | 20個の半月堡だけが水色で明滅する |
| 複合モードの選択 | イルミネーション候補は赤、タンバリン候補は青になる |
| `full_zones` | 外周の次、星形本体の前に点灯する |

## 外周

外周は`190..379`の190個を閉じたリングとして扱います。通常は`190`から`379`へ進み、末端を越えると`190`へ戻ります。模型上でも`379`と`190`が隣接するように配線してください。

`outer_comet`を再生すると金色の尾がリングを周回します。継ぎ目で光が飛んだり逆走したりする場合は、`379`と`190`の取り付け位置と配線方向を確認してください。

## 演出で配置を確認する

[イルミネーション一覧](illuminations.ja.md)の単独演出を使うと、ゾーンや配線方向を順番に確認できます。

| 演出キー | 確認できること |
| -------- | -------------- |
| `warm_white` | 星形本体の170個が途切れず点灯する |
| `ravelin_pulse` | 南西正面の半月堡20個だけが点灯する |
| `outer_comet` | 外周190個の順序と`379`→`190`の継ぎ目が連続する |
| `parallel_left` / `parallel_right` | 左右の5辺グループが表どおりに分かれる |
| `fireworks` | 星形の各A辺・B辺が中心から外側へ広がる |
| `full_zones` | 外周、半月堡、星形本体の3ゾーンが独立している |

初回は`warm_white`から始め、半月堡、外周、左右、花火の順に確認してください。電源と安全上の注意は[ハードウェア](hardware.ja.md)、単独演出の設定方法は[イルミネーション一覧](illuminations.ja.md)を参照してください。

## 配置を変更するとき

配線順やLED数を変更したら、次を一緒に更新・確認します。

- `led_layout.rb`のゾーン、セグメント、走査順
- `main.rb`の`led_count`
- 花火が星形の中心から外側へ進むこと
- 外周の`379`と`190`が連続して見えること
- Y-UPで組5が上になり、Z軸の振り方向で走査が反転すること
- 本資料と[構造資料](structure.ja.md)

変更後は上記の単独演出を再生し、資料の表と模型上の点灯位置が一致することを確認してください。
